OPTION 1: Validation simple (sans BD)
─────────────────────────────────────
from business_rules_engine import BusinessRulesEngine

engine = BusinessRulesEngine()

is_valid, errors = engine.validate_avenant(
    avenant_type="Changement adresse",
    documents=documents_list,
    contract_data={"is_active": True, "address": "..."}
)

if is_valid:
    print("✓ Valide!")
else:
    print("✗ Erreurs:", errors)


OPTION 2: Validation avec BD (RECOMMANDÉ)
──────────────────────────────────────────
from business_rules_engine import BusinessRulesEngine

engine = BusinessRulesEngine()

# Les données du contrat sont récupérées AUTOMATIQUEMENT!
is_valid, errors = engine.validate_avenant(
    avenant_type="Changement adresse",
    documents=documents_list,
    contract_id="CNT-2026-001"  # ← Auto récupéré depuis MySQL
)


OPTION 3: Flux complet (validation + mise à jour BD)
──────────────────────────────────────────────────────
# Récupérer le contrat
contract = engine.get_contract_info(email="client@example.com")

# Valider
is_valid, errors = engine.validate_avenant(
    "Changement adresse",
    documents,
    contract_id=contract['id']
)

# Appliquer (met à jour la BD automatiquement)
if is_valid:
    engine.apply_avenant(
        contract_id=contract['id'],
        avenant_type="Changement adresse",
        new_data={"address": "nouvelle adresse"},
        validation_errors=[]
    )

# Consulter l'historique
history = engine.get_contract_avenant_history(contract['id'])

❓ QUESTIONS FRÉQUENTES:

Q: Faut-il MySQL?
R: Non pour la validation de base. Oui si on veut le flux complet.

Q: Comment ajouter une nouvelle règle?
R: Modifier business_rules.json + ajouter vérification dans engine.py

Q: Comment tester sans MySQL?
R: Utiliser l'OPTION 1 (validation simple) avec contract_data manuel

Q: Les données sont à jour?
R: Oui! Elles viennent directement de la BD à chaque appel.

Q: Peut-on modifier les contrôles?
R: Oui! Modifiez business_rules.json et rechargez avec engine.reload_rules()
